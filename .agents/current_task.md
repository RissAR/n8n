# CURRENT TASK: Впровадження RBAC та повноцінної Адмін-панелі в Telegram Mini App

## 1. Мета задачі
Реалізувати Role-Based Access Control (RBAC) у Telegram Mini App та повноцінну панель адміністратора (Варіант А):
1. **Звичайний користувач (`user.id !== 8607080614`):** бачить виключно клієнтський квіз-калькулятор. Жодних адмінських елементів у DOM немає.
2. **Адміністратор (`user.id === 8607080614`):** у шапці додатка отримує перемикач вкладок:
   - `[ 🧮 Квіз-калькулятор ]` — для тестування клієнтського досвіду.
   - `[ 👑 Заявки (${count}) ]` — повноцінний дашборд лідів, підтягнутих у реальному часі з Google Таблиці через n8n.

---

## 2. Перелік файлів для створення та редагування

### 1) `src/types/admin.ts` (Типізація лідів)
Створити інтерфейс:
```typescript
export interface Lead {
  id: number;
  timestamp: string;
  userId: string;
  username: string;
  name: string;
  phone: string;
  repairType: string;
  propertyType: string;
  areaM2: string | number;
  addons: string;
  total: string;
  status: string;
}
```

### 2) `src/utils/auth.ts` (RBAC валідація)
Експортувати функцію перевірки ролі:
- Перевіряє чи ID користувача збігається з `import.meta.env.VITE_ADMIN_USER_ID || '8607080614'`.
- Для зручності локального тестування у звичайному браузері дозволяти адмінку за наявності параметра URL: `window.location.search.includes('admin=true')`.

### 3) `src/services/adminService.ts` (API запити до n8n)
- Метод `fetchAdminLeads(userId: string | number): Promise<Lead[]>`:
  - Відправляє `POST` на `import.meta.env.VITE_N8N_ADMIN_LEADS_URL` із `{ userId }`.
  - Повертає масив лідів `leads`.
  - Коректно обробляє помилки (включаючи `403 Forbidden`).

### 4) `src/components/AdminDashboard.tsx` (Інтерфейс адмін-панелі)
Створити сучасний екран керування заявками у графітово-бурштиновій гамі:
- **Блок аналітики (статистика вгорі):**
  - Кількість заявок всього
  - Кількість нових лідів
  - Загальна орієнтовна сума всіх кошторисів
- **Фільтрація за статусом:** чіпси `[ Всі ]`, `[ 🟡 Новий лід ]`, `[ 📞 В роботі ]`, `[ 📐 Замір ]`, `[ 🤝 Угода ]`.
- **Список карток клієнтів:**
  - Дата і час заявки
  - Ім'я клієнта та `@username`
  - Телефон клієнта (клікабельне посилання `<a href="tel:...">` з іконкою трубки)
  - Деталі об'єкта: тип ремонту, стан, площа м², обрані допи
  - Велика виділена сума розрахунку
  - Кольоровий статус-бейдж
- **Кнопка ручного оновлення (Refresh):** з анімацією спінера під час завантаження.
- **Стани інтерфейсу:** Loading Skeleton / Spinner, Порожній стан ("Заявок поки немає"), Помилка завантаження.

### 5) `src/App.tsx` (Інтеграція та перемикач вкладок)
- Якщо користувач є адміністратором (`isAdmin === true`):
  - Зверху рендериться фіксований таб-бар: `[ 🧮 Квіз ]` та `[ 👑 Заявки ]`.
  - При перемиканні на `👑 Заявки` монтується `<AdminDashboard />`.
- Якщо користувач не адміністратор: таб-бар не рендериться, користувач бачить тільки квіз.

## 3. Критерії приймання та перевірка (Verification)
1. Команда `npm run build` проходить без помилок компіляції TypeScript.
2. При запуску зі звичайного акаунта додаток виглядає як стандартний квіз.
3. При вході з Telegram акаунта з ID `8607080614` (або з `?admin=true`) з'являється вкладка «👑 Заявки».
4. Завантаження лідів підтягує реальні дані з Google Таблиці через захищений ендпоінт n8n.
