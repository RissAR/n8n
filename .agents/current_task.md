# CURRENT TASK: КРОК 3 — Нативний мобільний UX Mini App (Шліфовка фронтенду)

## 1. Мета задачі
Довести мобільний інтерфейс Telegram Mini App до нативного рівня системних додатків iOS/Android:
1. Безшовна темна шапка без сірих рамок Telegram.
2. Автоматичне розкриття на повну висоту екрана.
3. Захист від випадкового закриття свайпом вниз під час проходження квізу.
4. Нативна системна кнопка «Назад» (`Telegram.WebApp.BackButton`) у панелі Telegram на кроках 2–5.
5. Зручна маска українського номера телефону `+380 (XX) XXX-XX-XX` із валідацією.

---

## 2. Перелік файлів та вимоги

### 1) `src/utils/telegram.ts` (Розширення Telegram API хелперів)
Додати/оновити методи з безпечними перевірками:
- `initTelegramApp()`:
  - `WebApp.ready()`
  - `WebApp.expand()` (розкриття на весь екран)
  - `WebApp.setHeaderColor('#121518')` (темний колір системного бару)
  - `WebApp.setBackgroundColor('#121518')`
  - `WebApp.enableClosingConfirmation()` (попередження при спробі закрити свайпом)
- `showBackButton(onBack: () => void)`: показує системний `BackButton` і вішає колбек.
- `hideBackButton()`: приховує системний `BackButton`.

### 2) `src/App.tsx` (Інтеграція нативного BackButton)
- Викликати `initTelegramApp()` при монтуванні.
- Керувати видимістю `BackButton`:
  - Якщо активна вкладка `quiz` і `currentStep > 1` та `currentStep <= 5`: показувати `showBackButton` із функцією переходу на `currentStep - 1`.
  - Якщо `currentStep === 1` або екран успіху (крок 6) або вкладка `admin`: ховати `hideBackButton()`.
  - Очищати слухач при розмонтуванні компонентів.

### 3) `src/components/Step5Contact.tsx` (Маска та валідація номера телефону)
- Реалізувати інпут із маскою для українських номерів: `+380 (XX) XXX-XX-XX`.
- При введенні цифр автоматично підставляти дужки та дефіси.
- Дозволяти ввід тільки числових символів (після префіксу +380).
- Кнопка «Розрахувати кошторис» має бути заблокована (`disabled` + приглушений стиль), доки номер не містить повні 9 цифр після коду +380.

---

## 3. Критерії приймання та верифікація
1. Команда `npm run build` проходить без помилок компіляції TypeScript.
2. При переході з кроку 1 на крок 2 у лівому верхньому кутку вікна Telegram з'являється системна кнопка «Назад», натискання на яку плавно повертає на крок 1.
3. На кроці 5 телефон форматується автоматично у вигляді `+380 (50) 123-45-67`.
4. Шапка вікна Telegram не відрізняється за кольором від фону застосунку.
