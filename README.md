# 🔨 TMA «РемБригада Луцьк» — Онлайн-калькулятор ремонту та CRM

Комерційний веб-сервіс у форматі **Telegram Mini App (TMA)** для будівельної бригади «РемБригада Луцьк» (команда з 5 профільних майстрів без посередників), орієнтований на ринок міста Луцьк та прилеглих населених пунктів (Струмівка, Боратин, Липини, Зміїнець, Підгайці тощо).

Сервіс поєднує інтерактивний **квіз-калькулятор попереднього кошторису** для клієнтів та вбудовану **CRM-панель адміністрування лідів з рольовим доступом (RBAC)** для виконроба та менеджерів, інтегровану з **n8n Automation** та **Google Sheets**.

---

## 🚀 Технічний стек

### Frontend
- **Framework:** [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler:** [Vite 5](https://vitejs.dev/)
- **Styling:** [Tailwind CSS 3](https://tailwindcss.com/)
- **Design System:** Apple OneUI / Liquid Obsidian Glass (графітове матове скло `#0B0D11`, теплий бурштиновий градієнт `#F59E0B`/`#D97706`, плавні переходи, капсульні бейджі)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Telegram Integration:** Telegram WebApp API (підтримка теми, зворотного зв'язку Haptic Feedback, BackButton, автентифікації користувача)

### Backend & Automation
- **n8n Workflow Engine:** Автоматизація обробки лідів, розрахунків та зміни статусів
- **Database / Storage:** Google Sheets (як хмарна CRM-база лідів)
- **Notifications:** Telegram Bot API (сповіщення виконроба про нові заявки з інтерактивними inline-кнопками)

## 🌟 Основний функціонал

### 1. Інтерактивний калькулятор вартості (Квіз із 5 кроків)
1. **Крок 1: Формат робіт (`Step1Scope`)**
   - 🏢 *Вся квартира / Будинок під ключ*
   - 🚪 *Окреме приміщення під ключ* (ванна, кухня, спальня, балкон)
   - ⚡ *Спецмонтаж та інженерія* (електромонтаж, сантехніка, плитка)
2. **Крок 2: Деталі робіт (`Step2Detail`)**
   - Адаптивна зміна параметрів залежно від обраного формату:
     - Для всієї квартири: вибір класу ремонту (Косметичний 3 500 грн/м², Капітальний 7 500 грн/м², Дизайнерський 13 500 грн/м²) та типу об'єкта (Новобудова x1.0 / Вторинне житло x1.2).
     - Для окремого приміщення: Ванна кімната (25 000 грн фікс), Кухня (18 000 грн фікс), Спальня (3 500 грн/м²), Балкон (14 000 грн фікс).
     - Для інженерії: Електромонтаж (15 000 грн), Сантехніка (12 000 грн), Укладання плитки (600 грн/м²).
3. **Крок 3: Площа та обсяг (`Step3Area`)**
   - Динамічний слайдер з прямим числовим введенням та швидкими пресетами для розрахунків за площею.
   - Інформаційна картка фіксованого пакета робіт («Стандартне приміщення під ключ») для комплексних вузлів.
4. **Крок 4: Локальні додаткові послуги (`Step4Addons`)**
   - 🔨 Демонтаж та вивіз будсміття по Луцьку (+6 000 грн)
   - 🛒 Закупівля матеріалів зі знижкою до 20% в Епіцентрі Луцьк (+4 000 грн)
   - 📐 3D-візуалізація та технічний план комунікацій (+10 000 грн)
5. **Крок 5: Контакти та локація (`Step5Contact`)**
   - Автопідстановка імені користувача з Telegram.
   - Валідація українського номера телефону за маскою `+380 (XX) XXX-XX-XX`.
   - Вибір району Луцька (Центр/Старе місто, 33-й/40-й квартал, ЛПЗ/ДПЗ, Ковельська/Володимирська, Передмістя до 15 км).
   - Бажані терміни початку робіт.
6. **Крок 6: Фіксація результату (`Step6Success`)**
   - Відображення розрахованої вартості, персоналізоване повідомлення про виїзд виконроба Олега на безкоштовний замір та швидке закриття Telegram WebApp.

### 2. Адмін-панель CRM з RBAC (`AdminDashboard`)
- **Рольовий доступ (RBAC):** Доступ до вкладки «Заявки CRM» надається виключно адміністраторам за `Telegram User ID` або за URL-параметром `?admin=true` для тестування.
- **Аналітика в реальному часі:**
  - Загальна кількість заявок
  - Кількість нових лідів
  - Сумарний бюджет пайплайну
- **Фільтрація за статусами:** «Всі», «🟡 Нові», «📞 В роботі», «📐 Замір», «🤝 Угода».
- **Картка ліда:** Деталі замовлення (формат, метраж, район, додаткові послуги, телефон з можливістю дзвінка в 1 клік `tel:`).

## ⚙️ Встановлення та запуск

### 1. Клонування репозиторію та встановлення залежностей
```bash
git clone https://github.com/RissAR/n8n.git
cd n8n
npm install
```

### 2. Налаштування змінних оточення
Створіть локальний файл `.env` на основі `.env.example`:
```bash
cp .env.example .env
```

Заповніть змінні у `.env`:
```env
# n8n Webhook URLs
VITE_N8N_WEBHOOK_URL=https://your-n8n-instance.app.n8n.cloud/webhook/quiz-calculator
VITE_N8N_ADMIN_LEADS_URL=https://your-n8n-instance.app.n8n.cloud/webhook/admin-leads

# RBAC Configuration (Telegram ID адміністратора)
VITE_ADMIN_USER_ID=8607080614
```

### 3. Запуск у режимі розробки
```bash
npm run dev
```
Додаток запуститься локально за адресою `http://localhost:5173`.

Для тестування адмін-панелі без Telegram відкрийте:
`http://localhost:5173/?admin=true`

### 4. Тестування в Telegram Mini App
Для того щоб Telegram WebApp міг відкривати додаток, потрібен безпечний HTTPS-тунель:
```bash
# Приклад використання Cloudflare Tunnel:
cloudflared tunnel --url http://localhost:5173
```
Отриманий HTTPS-URL вкажіть у `@BotFather` у налаштуваннях меню або WebApp кнопки бота.

### 5. Збірка для продакшну
```bash
npm run build
```
Зібрані статичні файли розміщуються у директорії `dist/`.

## 🔄 Інтеграція з n8n (`quiz_calculator_workflow_v4.json`)

Робочий процес **v4 (Lutsk Edition)** автоматизує повний цикл обробки ліда:
1. **Webhook Receiver:** Приймає JSON-пейлоад форми з TMA (`/webhook/quiz-calculator`).
2. **Калькулятор:** Валідує та підраховує вартість за луцькою тарифною сіткою, форматує назви районів та додає часовий штамп за київським часом.
3. **Google Sheets:** Додає новий рядок у підключену таблицю Google Таблиць. Номер телефону екранується апострофом (`'+380...`), щоб запобігти помилкам розбору формул у таблицях.
4. **Сповіщення адміна:** Бот відправляє повідомлення виконробу з даними замовлення та інтерактивними кнопками (`📞 Взяв у роботу`, `📐 Замір`, `🤝 Угода`, `❌ Відхилено`).
5. **Callback Handler:** При натисканні кнопок оновлює статус у Telegram та в Google Таблиці.
6. **Admin Leads Endpoint:** Ендпоінт `/webhook/admin-leads` читає таблицю, перевіряє права доступу користувача (`userId === ADMIN_USER_ID`) та повертає масив лідів для відображення в CRM додатку.

## 🔒 Безпека та конфіденційні дані (Security Policy)

> [!WARNING]
> **Важливі вимоги безпеки для розробників та адміністраторів:**
> 1. **Файли `.env` та `.env.local`** додані до `.gitignore` і ніколи не повинні потрапляти у публічні коміти.
> 2. **Токени Telegram-ботів:** Усі токени формату `bot<token>` у файлах конфігурації n8n мають зберігатися у внутрішньому захищеному сховищі **Credentials n8n** або через змінні оточення `{{ $env.TELEGRAM_BOT_TOKEN }}`, а не як відкритий текст у коді чи схемах workflow.
> 3. **Google Sheets ID:** Доступ до робочих Google Таблиць повинен надаватися лише авторизованому Google Service Account / OAuth-акаунту.
> 4. Якщо будь-який токен бота потрапив у репозиторій або публічний доступ, його слід негайно відкликати та згенерувати новий у `@BotFather` через команду `/revoke`.
